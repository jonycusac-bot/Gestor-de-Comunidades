# Contexto de trabajo para agentes

Este repositorio es el único proyecto **Gestor de Comunidades / FincaFlow**. Antes de editar, lee `docs/CONTINUIDAD.md`, `README.md`, `package.json` y el código afectado. Comprueba `git status` y el último commit de `main`; el usuario también trabaja con otras herramientas y puede haber cambios nuevos.

Mantén el trabajo en este repositorio. No confundas la web de AI Studio, el despliegue antiguo de Cloudflare y el servidor local: son vistas o despliegues distintos, y un commit de GitHub no demuestra que una URL ya se haya actualizado.

Usa datos ficticios para la demo. No publiques datos reales de propietarios ni envíes correos reales. Antes de afirmar que algo funciona en la web, comprueba esa versión concreta. Para cambios de código, ejecuta `npm run lint` y `npm run build` cuando corresponda. Actualiza `docs/CONTINUIDAD.md` si cambia el estado o una decisión importante.
